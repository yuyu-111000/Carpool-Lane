# 挪车！师傅 · Carpool Lane

> 一款 AI Native 的 H5 休闲解谜游戏——师傅的车被堵死了，顺路捎上乘客、腾挪出一条活路，开出这条窄巷子。
> 参赛作品：AI Native 休闲游戏制作大赛（浙大专属场 · 乐信圣文）。

**打开即玩**：浏览器打开 [`dist/index.html`](dist/index.html)（单文件，零依赖，手机/PC 自适应）。

---

## 怎么玩

| 操作 | 说明 |
|---|---|
| 滑动 | 顺着车身方向拖动车辆（横车横移、竖车竖移） |
| 师傅掉头 | **垂直**于红车方向拖动，原地 90° 转向（第 1 关起） |
| 目标 | 把红色师傅车开出右侧出口 |
| 捎人 | 出口道闸锁着，先开到乘客旁接人，道闸才抬起；乘客也是障碍，接走后格子开放 |
| 按序接送 | 带编号的乘客须按顺序捎（第 4 章起） |
| 大关 | 每章第 10 关 = 7×7 放大地图 + 加长车 |

3 秒上手 · 30 秒乐趣 · 3 分钟想再来一局。星级 = 与求解器最优步数（par）的差距。

## 微创新（经典机制碰撞）

- **顺路捎人**：Rush Hour 空间腾挪 × 送快递路径规划，两子问题互相纠缠。
- **师傅掉头**：红车可纵向机动 → 乘客全图可放、解法空间变深，难度上限大幅抬高。
- **乘客即障碍**：接人 = 开闸 + 清障，双重收益。

## 50 关难度递进

5 章 × 10 关（小区 → 学校 → 写字楼 → 商场 → 机场），每章末 7×7 大关。
实测 par 曲线：ch1[3-5]+14 → ch4[6-17]+17 → ch5[8-16]+25，阶梯+波浪、章末峰值、高难后跟缓冲关。

## AI 驾驭力：三层独立实现交叉验证

1. **JS 规则内核**（游戏运行时）
2. **JS BFS 求解器**（关卡生产管线：可解性 + 最优步数 + 解路径窄度）
3. **Python 独立求解器**（端到端自动通关测试）

任何一层口径漂移都会立刻暴露——开发中实抓 8 处 bug。50 关 100% 求解器验证，`validate.js` 作 CI 门。

## 开发 / 重新生成关卡

```bash
cd game
npm test                 # 单元测试
node tools/pipeline.js   # 生成 50 关 + 难度曲线（seed 可复现）
node tools/validate.js   # CI 门：全量重验 + 曲线校验
npm run build            # 打包 dist/index.html
python tools/autoplay.py # Python 独立求解器端到端自动通关
```
